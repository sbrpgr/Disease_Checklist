## 데이터 타입 구조 (TypeScript)

```typescript
type Cancer = {
  id: string;                    // "liver", "thyroid", ...
  slug: string;                  // URL 슬러그
  name: string;                  // "간암"
  nameEn: string;                // "Liver Cancer"
  icon: string;                  // 이모지 또는 아이콘 키
  description: string;           // 1~2문장 요약
  affectedOrgan: string;         // 주요 발생 장기
  genderRisk: 'all' | 'male' | 'female' | 'male_dominant' | 'female_dominant';
  ageRisk: string;               // "50세 이상", "40~60대"
  incidenceRank: number;         // 국내 발생 순위 (국가암정보센터 기준)
  fiveYearSurvival: {            // 병기별 5년 생존율
    stage1: number;
    stage2: number;
    stage3: number;
    stage4: number;
  };

  earlySymptoms: Symptom[];      // 초기증상 목록
  redFlags: RedFlag[];           // 즉각 진료 필요 증상
  riskFactors: RiskFactor[];     // 위험요인
  checklist: ChecklistItem[];    // 자가진단 체크리스트

  diagnosticTests: string[];     // 권장 진단 검사
  screeningGuide: string;        // 국가검진 대상 여부 및 방법
  keyStatistic: string;          // 핵심 통계 1개 (사용자에게 임팩트 있는 수치)

  bodyParts: BodyPart[];         // 신체 부위 태그 (상향식 진단용)
  symptomTags: string[];         // 증상 태그 (상향식 진단용)

  references: string[];          // 주요 참고문헌
  lastUpdated: string;
};

type Symptom = {
  id: string;
  name: string;
  description: string;
  ppv?: number;          // 양성예측도 (%)
  frequency?: number;    // 발생률 (%)
  isRedFlag: boolean;
  bodyPart: string;
};

type RedFlag = {
  symptom: string;
  urgency: 'immediate' | 'within_48h' | 'within_2weeks';
  action: string;
};

type RiskFactor = {
  factor: string;
  relativeRisk?: string;   // "2~3배", "OR 7.26"
  isModifiable: boolean;   // 수정 가능 여부
};

type ChecklistItem = {
  id: string;
  question: string;
  weight: number;          // 1~5 (위험도 가중치)
  hint?: string;           // 선택 시 표시할 설명
  isRedFlag: boolean;      // true면 즉시 경고
};
```

## 1. 간암 (Liver Cancer)

**ID:** `liver` | **아이콘:** 🫀 | **발생 순위:** 6위 (국내)

### 핵심 통계
- 5년 생존율: 전체 37.0% (조기 발견 시 40~60%, 4기: 5% 미만)
- 조기(BCLC 0/A) 발견 비율: 23.5%에 불과
- 6개월 초음파+AFP 병행 검진이 조기발견율 37% 향상

### 초기증상
| 증상 | 발생률 | 특이사항 |
|---|---|---|
| 우상복부 통증/불쾌감 | 높음 | 가장 흔한 증상 |
| 황달 (눈/피부 황변) | 중간 | LR+ 매우 높음, 즉시 진료 |
| 복수 (배가 불러오는 느낌) | 진행 시 | 간경변과 구별 어려움 |
| 원인불명 체중감소 | 중간 | |
| 식욕 저하 | 높음 | 비특이적 |
| 극심한 피로 | 높음 | 비특이적 |
| 우상복부 종괴 촉지 | 진행 시 | |
| 위장관 출혈 | 6.4% | Red Flag |

### Red Flag
- 황달 → **즉시 병원**
- 복수(배가 갑자기 불러옴) → **1주일 내 진료**

### 위험요인
- B형 간염 (HBV) 만성 감염 — 가장 강력
- C형 간염 (HCV) 만성 감염
- 간경변 (어떤 원인이든)
- 과도한 음주 (장기)
- 비알코올성 지방간염 (NASH)
- 아플라톡신 노출

### 체크리스트 문항 (가중치)
1. 우상복부 통증이나 묵직한 느낌이 있나요? (w:2)
2. 황달 증상(눈 흰자·피부 노랗게)이 있나요? (w:5, RedFlag)
3. 복부가 팽팽하게 부어오르나요? (w:3)
4. 최근 체중이 빠르게 감소했나요? (w:2)
5. B형 또는 C형 간염 보유자인가요? (w:4)
6. 간경변 진단을 받은 적 있나요? (w:4)
7. 음주를 장기간 과도하게 했나요? (w:2)
8. 설명 없는 심한 피로가 지속되나요? (w:1)

### 진단 검사
- 1차: 복부 초음파 + AFP (6개월 간격, 고위험군)
- 확진: 조영증강 CT 또는 MRI
- KLCA-NCC 2022 권고: B형·C형 간염 또는 간경변 환자 6개월마다 필수

## 2. 갑상선암 (Thyroid Cancer)

**ID:** `thyroid` | **아이콘:** 🔵 | **발생 순위:** 1위 (여성)

### 핵심 통계
- 5년 생존율: 99% 이상 (유두암·여포암), 미분화암은 예외
- 성대마비(VCP) PPV: 76% — 가장 강력한 단일 증상
- 경부 림프절 비대 PPV: 68%, NPV: 80%
- 과잉진단 주의: WHO/IARC 추산 여성에서 50~90%가 과잉진단

### 초기증상
| 증상 | 발생률 | PPV |
|---|---|---|
| 목 앞 결절(혹) — 무통성 | 흔함 | — |
| 쉰 목소리/목소리 변화 (성대마비) | 1.3% | 76% |
| 삼킴 불편(연하 곤란) | 약 80% | — |
| 호흡 곤란 | 약 32% | — |
| 목 압박감·꽉 찬 느낌 | 중간 | — |
| 경부 림프절 비대 (>1cm) | 중간 | 68% |
| 기침·질식감 | 중간 | — |

### Red Flag
- 목소리 갑자기 쉬어짐 (1개월 이상) → **2주 내 진료**
- 삼킴이 갑자기 어려워짐 → **2주 내 진료**

### 위험요인
- 두경부 방사선 치료 이력
- 가족력 (특히 유두암)
- 여성 (남성 대비 3~4배)
- MEN2, FAP 등 유전 증후군
- 요오드 결핍/과잉

### 체크리스트 문항
1. 목 앞부분에 혹이나 덩어리가 느껴지나요? (w:4)
2. 목소리가 1개월 이상 쉬거나 변했나요? (w:5, RedFlag)
3. 음식을 삼키기 불편한 느낌이 있나요? (w:3)
4. 숨쉬기 불편하거나 호흡 곤란이 있나요? (w:3)
5. 목 림프절이 부었나요? (w:3)
6. 가족 중 갑상선암 환자가 있나요? (w:3)
7. 목이나 머리에 방사선 치료를 받은 적 있나요? (w:4)

### 진단 검사
- 1차: 경부 초음파 + TSH 검사
- 확진: 세침흡인세포검사 (FNA)
- 추가: 경부 CT/MRI (림프절 전이 평가)
- USPSTF: 무증상 일반인 선별검사 권고 안 함

## 3. 난소암 (Ovarian Cancer)

**ID:** `ovarian` | **아이콘:** 🟣 | **발생 순위:** 여성 9위

### 핵심 통계
- 5년 생존율: 1기 92%, 2기 76%, 3기 29%, 4기 13%
- CA-125 단독 PPV: 1% 미만 (일반 인구)
- Goff Symptom Index 민감도: 56.9~83.3%
- 조기(I/II기)에서 증상 민감도 44.8% — 초기 증상이 더 적음

### 초기증상 (Goff Symptom Index 4대 증상)
| 증상 | 발생률 | 핵심 기준 |
|---|---|---|
| 복부 팽만 (bloating) | 17~64% | **12개월 이내 신규 발생 + 월 12회 이상** |
| 골반/복부 통증 | 중간 | 지속성 여부 중요 |
| 조기 포만감 (조금만 먹어도 배 부름) | 중간 | |
| 빈뇨/절박뇨 | 중간 | |
| 복부 팽창 | 5~68% | |
| 피로감 | 중간 | 비특이적 |
| 배변 습관 변화 | 중간 | |
| 허리 통증 | 중간 | |

### Red Flag
- 위 4대 증상이 **2~3주 이상 지속** + **12개월 이내 새로 시작** → **2~4주 내 진료**

### 위험요인
- BRCA1 변이: 평생 위험도 39~44%
- BRCA2 변이: 17~18%
- Lynch 증후군
- 자궁내막증
- 가족력 (1촌 난소암 환자)
- 난임/불임, 폐경 후 호르몬 치료 장기

### 체크리스트 문항 (NICE 기준 변형)
1. 복부가 팽팽하게 부은 느낌이 자주(월 12회 이상) 있나요? (w:4)
2. 조금만 먹어도 금방 배가 부르나요? (w:3)
3. 골반이나 하복부에 통증이 있나요? (w:3)
4. 소변이 자주 마렵거나 참기 어렵나요? (w:2)
5. 위 증상이 12개월 이내에 새롭게 생겼나요? (w:2)
6. 위 증상이 2~3주 이상 지속되고 있나요? (w:3)
7. 가족 중 난소암이나 유방암(BRCA) 환자가 있나요? (w:4)
8. 자궁내막증이나 난소낭종 진단을 받은 적 있나요? (w:2)

### 진단 검사
- 고위험군: CA-125 + 경질 초음파
- NICE: 50세 이상 여성 지속 증상 시 CA-125 우선
- USPSTF: 일반 인구 선별검사 권고 안 함 (D등급)

## 4. 담낭암 (Gallbladder Cancer)

**ID:** `gallbladder` | **아이콘:** 🟡 | **발생 순위:** 비교적 드묾

### 핵심 통계
- 황달의 LR+: **206** (가장 강력한 단일 Red Flag)
- 우연 발견(iGBC) 비율: 담낭 절제술 후 약 0.7%
- 담석 OR: 7.26 (가장 강력한 위험인자)
- 담낭 용종 OR: 1.88

### 초기증상
| 증상 | 발생률 |
|---|---|
| 우상복부 통증 | 37.3% (가장 흔함) |
| 오심·구역질 | 23.4% |
| 황달 | 진행 시, LR+ 206 |
| 체중 감소 | 15.2% |
| 발열 | 중간 |
| 식욕 부진 | 중간 |
| 등/어깨 방사통 | 중간 |

### Red Flag
- 황달 발생 → **즉시 응급 진료**

### 위험요인
- 담석 (OR 7.26) — 가장 강력
- 담낭 용종 (>1cm 특히 위험)
- 여성 (3~4배)
- 고령 (65세 이상)
- 비만, 만성 담낭염

### 체크리스트 문항
1. 식사 후(특히 기름진 음식) 우상복부 통증이 있나요? (w:3)
2. 황달(눈 흰자·피부 노란빛) 증상이 있나요? (w:5, RedFlag)
3. 구역질이나 구토가 반복되나요? (w:2)
4. 최근 체중이 이유 없이 감소했나요? (w:2)
5. 담석 또는 담낭 용종 진단을 받은 적 있나요? (w:4)
6. 50세 이상이며 증상이 1~2개월 이상 지속되나요? (w:2)

### 진단 검사
- 혈액: CA19-9, 간기능검사 (ALP·GGT·빌리루빈)
- 영상: 복부 초음파 → CT → MRI/MRCP
- 담낭 용종 추적: 5년간 6~12개월 간격 초음파

## 5. 대장암 (Colorectal Cancer)

**ID:** `colorectal` | **아이콘:** 🩸 | **발생 순위:** 3위 (국내)

### 핵심 통계
- 5년 생존율: 1기 95%, 2기 80%, 3기 70%, 4기 22%
- 혈변 PPV: 약 4.0% (60세 이상: 3.0~4.5%)
- "혈변 + 배변습관 변화" 복합 PPV: **9~11%** (급격히 상승)
- 혈변 NPV: 99.4% (혈변 없어도 안심 금물)

### 초기증상
| 증상 | 발생률 | PPV |
|---|---|---|
| 직장 출혈·혈변 | 17% | 4.0% (복합 시 9~11%) |
| 배변 습관 변화 (4주 이상) | 14.9% | — |
| 변이 가늘어짐 | 중간 | — |
| 복통·경련 | 13.8% | — |
| 원인불명 체중감소 | 12.8% | — |
| 빈혈 증상(피로·창백함) | 중간 | — |
| 잔변감 | 중간 | — |
| 변에 점액 혼합 | 중간 | — |

### Red Flag
- 혈변 (적색 또는 흑색) → **2주 내 진료**
- 혈변 + 배변 습관 변화 동시 → **즉시 진료**

### 위험요인
- 50세 이상
- 대장 선종(폴립) 병력
- 가족력 (FAP, Lynch 증후군 포함)
- 과도한 적색육·가공육 섭취
- 비만, 운동 부족, 흡연, 음주
- 염증성 장질환

### 체크리스트 문항
1. 변에 피가 섞이거나 변기에 피가 보이나요? (w:4, RedFlag)
2. 배변 습관이 4주 이상 변했나요(변비/설사/빈도 변화)? (w:3)
3. 이유 없이 체중이 감소하고 있나요? (w:2)
4. 복통이나 경련이 지속되나요? (w:2)
5. 심한 피로감이나 창백함이 있나요?(빈혈 의심) (w:2)
6. 가족 중 대장암 또는 대장 폴립 환자가 있나요? (w:3)
7. 50세 이상이며 대장암 검진을 최근 2년 내 안 받았나요? (w:2)

### 진단 검사
- 1차 선별: 분변잠혈검사(FIT) — 45~80세 1~2년마다
- NICE: FIT ≥10 μg Hb/g 시 대장내시경 의뢰
- 확진: 대장내시경 + 조직검사
- 국내: 50세 이상 1년마다 FOBT

## 6. 방광암 (Bladder Cancer)

**ID:** `bladder` | **아이콘:** 💧 | **발생 순위:** 남성 10위권

### 핵심 통계
- 육안적 혈뇨 PPV: **28.3%** (특이도 99.8%) — 가장 강력한 단일 증상
- 55~74세 혈뇨 PPV: 7.1%
- 현미경적 혈뇨 PPV: 3.4%
- UTI 오진 후 적절한 검사까지 평균 81.5일 지연

### 초기증상
| 증상 | 발생률 | PPV |
|---|---|---|
| 육안적 혈뇨 | 17% | 28.3% |
| 현미경적 혈뇨 | 3.3% | 3.4% |
| 배뇨 시 통증·작열감 | 중간 | — |
| 빈뇨 | 중간 | — |
| 급뇨 | 중간 | — |
| 야간뇨 | 중간 | — |

### Red Flag
- 육안적 혈뇨 (소변이 붉거나 분홍색) → **즉시 진료**
- 요로감염 치료 후에도 지속되는 혈뇨 → **즉시 재검사**

### 위험요인
- 흡연 (위험도 2~3배) — 가장 강력
- 방향족 아민 직업 노출 (염료·고무·가죽 산업)
- 고령 (60세 이상), 남성 (3~4배)
- 만성 방광 자극, 사이클로포스파마이드 항암제 치료력

### 체크리스트 문항
1. 소변이 붉거나 분홍색, 갈색으로 변한 적 있나요? (w:5, RedFlag)
2. 배뇨 시 통증이나 타는 느낌이 있나요? (w:2)
3. 소변이 자주 마렵거나 갑자기 참기 어렵나요? (w:2)
4. 요로감염으로 치료해도 혈뇨가 계속되나요? (w:4, RedFlag)
5. 흡연을 하거나 과거 흡연력이 있나요? (w:2)
6. 직업상 화학물질(염료·고무·가죽)에 노출된 적 있나요? (w:3)
7. 40세 이상인가요? (w:1)

### 진단 검사
- 소변 검사 + 요세포검사
- 방광 초음파 → CT 요로조영술
- 확진: 방광경 (Cystoscopy)
- AUA 위험도 분류: 고위험(60세↑, 혈뇨多, 고위험인자) → 즉시 방광경+CT

## 7. 백혈병 (Leukemia)

### 핵심 통계
- 소아 ALL 5년 생존율: 85~90%

5. 목·겨드랑이·사타구니 림프절이 부었나요? (w:3)
6. 왼쪽 상복부가 묵직하거나 팽만감이 있나요? (w:3)
7. 위 증상 중 2가지 이상 동시에 있나요? (w:4, RedFlag)

### 진단 검사
- 필수: 전혈구검사 (CBC + 혈액도말) — NICE: 48시간 이내
- 확진: 골수 생검·흡인, 세포유전학검사
- CML 확진: BCR-ABL 융합유전자 (PCR, FISH)

| 식욕 저하 | 중간 | |

### Red Flag
- 연하곤란 (새로 생긴 삼킴 어려움) → **즉시~2주 내 내시경**
- NICE: 연하곤란 단독으로 의심암 경로 의뢰
- 55세 이상 + 체중감소 + 역류/소화불량 → **2주 내 내시경**

### 위험요인
- 흡연 (가장 강력)
- 과도한 음주

- 고령, 남성 (남:여 = 3~4:1)
- 아칼라지아, 부식제 섭취 이력

### 체크리스트 문항

3. 이유 없이 체중이 감소하나요? (w:3)
4. 역류나 속쓰림이 오래 지속되거나 치료에도 안 낫나요? (w:2)
5. 흉골 뒤가 타는 듯하거나 통증이 있나요? (w:2)
6. 흡연 또는 과도한 음주를 하나요? (w:2)
7. 55세 이상인가요? (w:1)

### 진단 검사
- 1차: 상부위장관 내시경
- NICE NG12: 연하곤란 시 의심암 경로 즉시 의뢰
- ACG GERD 2022: 경고증상 동반 GERD 시 상부내시경 권고
- Edinburgh Dysphagia Score 활용 위험 층화

## 10. 유방암 (Breast Cancer)

**ID:** `breast` | **아이콘:** 🩷 | **발생 순위:** 여성 1위

### 핵심 통계
- 5년 생존율: 1기 99%, 2기 93%, 3기 72%, 4기 28%

### Red Flag
- 유두 혈성 분비물 → **2~4주 내 진료**
- 유방 피부 오렌지 껍질 모양 → **즉시~2주 내 진료**
- 새로 생긴 유두 함몰 → **2주 내 진료**

### 위험요인
- 가족력 (1촌 유방암: 위험도 2~3배)
- BRCA1/2 변이 (평생 위험도 50~80%)
- 고령 (40세 이상부터 증가)
- 이전 유방 조직검사에서 비정형세포
- 장기 호르몬 대체요법
- 음주, 비만 (폐경 후), 방사선 치료 이력

### 체크리스트 문항 (BSE 기반)
1. 유방에 새로운 덩어리나 단단한 부위가 느껴지나요? (w:4)
2. 유두에서 분비물(특히 혈성)이 나오나요? (w:5, RedFlag)
3. 유방 피부가 오렌지 껍질처럼 울퉁불퉁해졌나요? (w:5, RedFlag)
4. 유두가 안으로 함몰되었나요 (새로 생긴 경우)? (w:4, RedFlag)
5. 겨드랑이에 멍울이 느껴지나요? (w:3)
6. 가족 중 유방암 환자가 있나요? (w:3)
7. 유방 크기나 모양이 변했나요? (w:2)

### 진단 검사
- 1차: 유방 X선 촬영(맘모그래피) — 국내 40~69세 2년마다 국가검진
- 추가: 유방 초음파 (고밀도 유방 조직)
- 확진: 조직검사 (총생검 또는 절제생검)
- 고위험군: MRI (BRCA 보유자 등)

7. 이유 없이 체중이 감소하나요? (w:2)

### 진단 검사
- **고위험군 선별**: 저선량 CT (LDCT) — 국내 54~74세, 30갑년 이상 흡연자 국가검진
- 1차 영상: 흉부 X선
- 확진: 기관지경 + 조직검사, CT 유도 생검
- 혈액: 종양표지자 (보조적)

## 13. 피부암 (Skin Cancer)

**ID:** `skin` | **아이콘:** 🌞 | **발생 순위:** 드묾, 흑색종은 치명적

### 핵심 통계
- 비흑색종 피부암(기저세포암·편평세포암): 치료 후 생존율 95%↑
- 흑색종 5년 생존율: 1기 98%, 4기 23%
- ABCDE 법칙: 흑색종 민감도 89~100%, 특이도 65~97%
- 더모스코피 민감도: 89%, 특이도 79%

### 초기증상 (ABCDE 법칙)
| 항목 | 내용 | 주의 기준 |
|---|---|---|
| **A** symmetry (비대칭) | 점을 반으로 나눴을 때 양쪽이 다름 | 비대칭 = 주의 |
| **B** order (경계) | 경계가 불규칙하거나 들쭉날쭉 | 불규칙 = 주의 |
| **C** olor (색) | 한 점 내 여러 색 (갈색, 검정, 빨강, 흰색 혼재) | 다색 = 주의 |
| **D** iameter (크기) | 직경 6mm 이상 (지우개 크기) | 6mm↑ = 주의 |
| **E** volution (변화) | 크기·색·모양·두께가 변하거나 출혈 | 변화 = 즉시 확인 |

추가 증상:
- 잘 낫지 않는 상처 또는 반복 출혈 → Red Flag (기저세포암)
- 딱딱하고 거친 붉은 반점 (편평세포암 전구)
- 새로 생긴 점 또는 기존 점의 변화

### Red Flag
- E(변화): 점이 급격히 변하거나 출혈 → **2주 내 진료**
- 잘 낫지 않는 피부 상처 (4주 이상) → **2주 내 진료**

### 위험요인
- 자외선(UV) 노출 (흑색종 가장 강력한 원인)
- 흰 피부·밝은 눈·금발/적발
- 선번(sunburn) 이력 (특히 어린 시절)
- 선천성 거대 색소모반
- 면역 억제 치료
- 가족력 (흑색종)
- 선일광각화증 (편평세포암 전구)

### 체크리스트 문항 (ABCDE 기반)
1. 점의 양쪽 절반이 서로 다른 모양인가요? (비대칭) (w:3)
2. 점의 경계가 불규칙하거나 들쭉날쭉한가요? (w:3)
3. 한 점 안에 여러 색이 섞여 있나요? (w:4)
4. 점의 크기가 6mm(연필 지우개) 이상인가요? (w:3)
5. 점이나 피부 병변이 최근 변하고 있나요(크기·색·모양)? (w:5, RedFlag)
6. 피부 상처가 4주 이상 낫지 않거나 반복 출혈이 있나요? (w:4, RedFlag)
7. 자외선 차단 없이 야외활동을 많이 하거나 선번 이력이 있나요? (w:2)

### 진단 검사
- 시각적 검사: ABCDE 법칙, 전신 피부 검사
- 더모스코피 (Dermoscopy) — 1차의료 확대 가능
- 확진: 피부 조직검사 (생검)
