## 1. 프로젝트 개요

### 1.1 서비스 정보
| 항목 | 내용 |
|---|---|
| **서비스명** | 질환 체크리스트 |
| **도메인 (안)** | `checklist.health` / `jilhwan.com` / `cancercheck.kr` |
| **서비스 유형** | 의료 정보 / 암 자가진단 플랫폼 |
| **수익 모델** | Google AdSense 광고 수익 (장기: 제휴 광고, 검진 기관 연계) |

| **플랫폼** | 웹 (모바일 퍼스트), PWA 지원 예정 |

### 1.2 서비스 비전
> "증상이 걱정될 때, 근거 있는 첫 번째 체크포인트"

암에 대한 막연한 불안을 해소하고, 의료기관 방문 전 스스로 점검해볼 수 있는
**신뢰할 수 있는 의학 근거 기반** 자가진단 플랫폼

### 1.3 핵심 가치
1. **신뢰성** — 국립암센터, 대한암학회, NCC·NICE·ACS 가이드라인 기반
2. **접근성** — 의학 지식 없이도 쉽게 이해하는 쉬운 언어
3. **유용성** — 자가진단 결과에 따른 명확한 다음 행동 안내
4. **책임성** — 자가진단은 진료 대체 불가 명시, E-E-A-T 원칙 준수

## 2. 서비스 구조

### 2.1 전체 서비스 맵

```
질환 체크리스트
│
├── 🏠 홈 (메인)
│   └── 검색바 · 빠른 진입 CTA · 주요 암 카드 · 최신 뉴스
│
├── 🔍 자가진단 (핵심 서비스)
│   ├── [하향식] 암 선택 → 증상 체크리스트 → 위험도 결과
│   └── [상향식] 증상 입력 → 가능한 암 목록 → 상세 체크리스트
│
├── 📚 암 정보 라이브러리 (암별 상세 정보 페이지 × 13종)
│
├── 📰 뉴스 & 연구 (최신 암 연구 · 국가검진 정보 · 건강 뉴스)
│
├── 🏥 검진 기관 안내 (국가암검진 대상·일정·기관 링크)
│
└── ℹ️ 부가 페이지 (소개 · 이용약관 · 개인정보처리방침 · 문의)
```

### 2.2 핵심 서비스: 자가진단 시스템

#### A. 하향식 진단 (Top-Down) — "이 암이 걱정돼요"
> 사용자가 의심하는 암을 먼저 선택 후 증상 체크

```
암 선택 → 기본 정보 확인 → 체크리스트 응답 (예/아니오/모르겠음) →
위험 신호 감지 시 즉시 알림 → 종합 위험도 결과 →
권장 행동 안내 (자기 관찰 / 진료 권고 / 즉시 병원)
```

**특징**
- 각 증상 항목에 "이게 뭔가요?" 팝업 (쉬운 설명)
- Red Flag 증상은 별도 강조 처리
- 응답 중 Red Flag 발견 시 즉각 "지금 병원에 가세요" 인터럽트 표시
- 결과 화면에 위험도 시각화 (점수바, 색상 코드)
- 결과 인쇄/저장 기능 (의사 방문 시 지참 용도)

#### B. 상향식 진단 (Bottom-Up) — "이런 증상이 있어요"
> 현재 증상을 선택하면 관련 암 가능성을 탐색

```
신체 부위 선택 또는 증상 검색 →
증상 복수 선택 (최대 10개) →
증상 기간 / 강도 입력 →
연관 암 목록 + 각 암별 위험 관련도 표시 →
각 암 상세 체크리스트로 이동 CTA
```

**특징**
- 신체 부위별 시각적 선택 (인체 일러스트 or 부위 버튼)
- 증상 텍스트 검색 지원
- "암이 아닐 수도 있는 경우" 함께 안내 (과잉불안 방지)
- 증상 조합별 PPV(양성예측도) 정보 표시

#### C. 공통 UX 원칙
- 모든 진단은 면책 고지 먼저: "이 결과는 의학적 진단이 아닙니다"
- 결과 저장 없음 (개인정보 최소 수집, 로그인 불필요)
- 1회 진단 완료 시 관련 검진 기관 찾기 CTA 노출

## 3. 대상 암 종류 (13종)

| 4 | **담낭암** | 여성 多 | 우상복부 통증, 황달, 구역질 | 담석, 담낭 용종 |
| 5 | **대장암** | 공통 | 혈변, 배변 습관 변화, 복통 | 50세 이상, 폴립, 가족력 |

| 8 | **식도암** | 남성 多 | 연하 곤란, 체중 감소, 흉통 | 흡연, 음주, 역류성 식도염 |
| 9 | **신장암** | 남성 多 | 혈뇨, 옆구리 통증, 복부 종괴 | 흡연, 비만, 고혈압 |

| 12 | **폐암** | 공통 | 만성 기침, 객혈, 호흡 곤란 | 흡연 (가장 강력), 미세먼지 |

## 4. 증상-암 매핑 (상향식 진단 핵심 데이터)

| 증상 | 관련 암 (위험도 순) | 즉시 병원 기준 |
|---|---|---|
| 혈뇨 (육안) | 방광암 (PPV 28.3%) > 신장암 > 전립선암 | 즉시 |
| 혈변 / 흑색변 | 대장암 > 위암 | 즉시 |
| 황달 | 담낭암 (LR+ 206) > 간암 > 췌장암 | 즉시 |
| 혈담 / 객혈 | 폐암 > 식도암 | 즉시 |
| 목 결절 | 갑상선암 > 림프종 | 1~2개월 내 |
| 유방 종괴 | 유방암 | 2~4주 내 |
| 연하 곤란 | 식도암 > 갑상선암 > 폐암 | 1개월 내 |
| 복부 팽만 (지속) | 난소암 > 간암 > 대장암 | 2~3주 내 |
| 원인불명 체중감소 | 폐암 > 위암 > 대장암 > 췌장암 | 2주 내 |
| 피로+발열+출혈경향 | 백혈병 | 즉시 (CBC 48h) |
| 배뇨 곤란 | 전립선암 > 방광암 | 4주 내 |
| 피부 병변 변화 | 피부암 (흑색종) | 1개월 내 |
| 만성 기침 (8주↑) | 폐암 > 식도암 | 4주 내 |
| 우상복부 통증 | 간암 > 담낭암 | 지속 시 2주 내 |

## 5. 페이지 구성 상세

### 5.1 홈페이지 (`/`)
- **Hero 섹션**: 검색바 + "지금 증상이 있어요" / "특정 암이 걱정돼요" 두 개 CTA 버튼
- **암 종류 카드 그리드**: 13종 암 아이콘 카드 (발생률 순 정렬)
- **자가진단 가이드**: 서비스 이용 방법 3단계 설명
- **최신 뉴스 섹션**: 최근 암 연구/검진 정보 3~4개
- **신뢰 지표**: 출처 기관 로고 (국립암센터, NCC, 대한암학회 등)
- **면책 고지 배너**: 하단 고정

### 5.2 암 정보 페이지 (`/cancers/[slug]`)
각 암 고유 페이지 — AdSense에서 가장 가치 높은 콘텐츠 페이지

**섹션 구성:**
1. 개요 (정의, 유병률, 국내 통계)
2. 초기증상 상세 설명 (증상별 PPV/발생률 포함)
3. Red Flag 증상 강조 카드
4. 위험요인 체크리스트
5. 권장 검진 및 진단 방법
6. 병기별 생존율 차트
7. 자가진단 시작 CTA
8. 관련 공신력 있는 외부 링크 (국립암센터, 건강보험공단 등)
9. 참고문헌 목록 (출처 투명성)

### 5.3 하향식 자가진단 (`/cancers/[slug]/check`)
- 진행 바 표시 (총 N단계 중 X단계)
- 한 화면에 1~2개 질문 (모바일 최적화)
- 각 질문 항목에 설명 팝업
- Red Flag 감지 시 즉시 인터럽트
- 결과 페이지: 위험도 수준 (낮음/주의/높음) + 권장 행동

### 5.4 상향식 자가진단 (`/symptom-check`)
- Step 1: 신체 부위 선택 (머리/목/흉부/복부/비뇨기/피부/전신)
- Step 2: 증상 목록 체크 (다중 선택)
- Step 3: 증상 기간 및 강도 입력
- Step 4: 결과 — 관련 암 카드 (위험도 그래디언트 표시)
- 각 암으로 상세 체크리스트 이동 링크

### 5.5 뉴스 & 연구 (`/news`)
- 국가암검진 일정 및 제도 변경 사항
- 최신 암 연구 뉴스 (큐레이션 + 간략 요약)
- 암 예방 건강 팁 콘텐츠
- 카테고리 필터 (암 종류별)

### 5.6 검진 기관 안내 (`/screening`)
- 국가암검진 대상 암종 및 지원 연령 안내 표
- 검진 종류별 설명 (무엇을 검사하는가)
- 건강보험공단 검진 예약 링크
- 주요 암센터 목록 (공공기관 데이터 기반)

### 5.7 AdSense 필수 페이지
- `/about` — 서비스 소개 및 팀/운영자 정보
- `/privacy` — 개인정보처리방침
- `/terms` — 이용약관
- `/contact` — 문의 양식
- `/disclaimer` — 의료 면책 고지

## 6. Google AdSense 승인 전략

### 6.1 E-E-A-T 원칙 적용 (Experience · Expertise · Authoritativeness · Trustworthiness)

| 원칙 | 적용 방법 |
|---|---|
| **경험(Experience)** | 각 콘텐츠에 "이 정보는 OOO 가이드라인을 기반으로 작성" 명시 |
| **전문성(Expertise)** | 의학 용어 쉬운 설명 + 전문 용어 병기, 참고문헌 목록 |
| **권위성(Authority)** | 국립암센터, 대한암학회, WHO 등 공신력 있는 출처 인용 |
| **신뢰성(Trust)** | 면책 고지, 개인정보처리방침, 운영자 정보, 연락처 제공 |

### 6.2 AdSense 승인을 위한 콘텐츠 기준 (구글 가이드라인 기반)

**구글이 권장하는 고품질 콘텐츠 원칙:**
1. **독창성** — 타 사이트 단순 복사 금지, PDF 자료를 독자적으로 재구성
2. **차별화** — 증상별 PPV(양성예측도) 데이터 포함, 국내 기준 특화
3. **약속 이행** — 자가진단 기능이 실제로 동작하고 유용한 결과 제공
4. **사용자 초점** — 광고보다 콘텐츠가 압도적으로 많아야 함
5. **중복 금지** — 13개 암 페이지 각각 고유한 충분한 콘텐츠 (최소 2,000자 이상)

### 6.3 광고 배치 전략 (콘텐츠 > 광고 원칙)

| 페이지 유형 | 광고 위치 | 광고 수 |
|---|---|---|
| 암 정보 페이지 | 본문 중간 (2,000자 이후), 사이드바, 하단 | 최대 3개 |
| 뉴스 페이지 | 기사 하단, 목록 사이 | 최대 2개 |
| 홈페이지 | 암 카드 그리드 사이 (중간), 하단 | 최대 2개 |
| 자가진단 페이지 | **광고 없음** (사용자 경험 최우선) | 0개 |
| 결과 페이지 | 결과 하단만 | 최대 1개 |

**광고 금지 페이지:**
- 자가진단 체크리스트 진행 중
- 404 오류 페이지
- 개인정보처리방침, 이용약관

### 6.4 AdSense 심사 대비 체크리스트
- [ ] 최소 15개 이상 고품질 페이지 (각 암 정보 13개 + 부가 페이지)
- [ ] 각 페이지 2,000자 이상 원본 콘텐츠
- [ ] 운영자 정보 About 페이지 완성
- [ ] 개인정보처리방침 페이지 완성
- [ ] 면책 고지 전 페이지 하단 고정
- [ ] 내비게이션 명확, 404 페이지 커스텀
- [ ] 모바일 반응형 완벽 지원
- [ ] 페이지 로딩 속도 (Core Web Vitals 그린 목표)
- [ ] HTTPS (Vercel 기본 제공)
- [ ] 외부 링크 신뢰할 수 있는 의료기관만

## 7. SEO 전략

### 7.1 키워드 전략

**핵심 키워드 (검색량 높음)**
- `[암종류] 초기증상` (예: 폐암 초기증상, 대장암 초기증상)
- `[암종류] 자가진단`
- `[암종류] 증상 체크리스트`

**롱테일 키워드 (전환율 높음)**
- `[증상]이 있으면 무슨 암인가요`
- `[증상] 암인지 구별 방법`
- `[암종류] 몇 기 증상`

**뉴스/정보성 키워드**
- `2026 국가암검진 대상자`
- `[암종류] 최신 치료 방법`

- `MedicalCondition` — 각 암 정보 페이지

- `Article` — 뉴스 페이지
- `BreadcrumbList` — 전체 페이지

### 7.3 페이지별 SEO 설정
- 동적 메타 태그 생성 (Next.js Metadata API)

### 9.1 브랜드 톤
- **신뢰감 있고 차분한** 의료 정보 서비스 느낌
- 너무 무겁거나 무서운 분위기 지양
- "걱정을 해소해주는" 따뜻한 느낌

### 9.2 색상 팔레트
| 역할 | 색상 | 용도 |
|---|---|---|
| Primary | `#2563EB` (블루) | 메인 CTA, 링크 |
| Success | `#16A34A` (그린) | 위험도 낮음 |
| Warning | `#D97706` (앰버) | 위험도 중간/주의 |
| Danger | `#DC2626` (레드) | Red Flag, 위험도 높음 |
| Neutral | `#F8FAFC` 배경, `#1E293B` 텍스트 | 기본 레이아웃 |

### 9.3 타이포그래피
- 한글: Pretendard (가독성 최고)
- 영문/숫자: Inter
- 제목: 굵고 크게 (신뢰감)
- 본문: 16px, 1.7 line-height (읽기 편함)
